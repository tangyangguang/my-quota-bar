# My Quota Bar

一个 macOS 菜单栏应用，常驻菜单栏查看多个账号下各项服务的剩余额度。**本机应用，纯本地运行，不上传任何数据，零命令行依赖。**

> 项目背景与设计原则见 [PROJECT_RULES.md](./PROJECT_RULES.md)（唯一权威文档）。

## 信息层级

**平台 → 账号 → 服务 → 服务实例 → 额度**。面板先按平台、再按账号分组；账号内顺序为 Agent Plan → Coding Plan → 语音。语音 AppID 是语音服务内部实例。

## 当前支持

- **火山引擎 · Agent Plan**
  - 5 小时 / 每周 / 每月 三个窗口：进度条 + 剩余百分比 + 已用/总量 + 重置时间
  - 数据来源：火山 OpenAPI `GetAFPUsage`，用账号 AK/SK 签名调用（**无需 arkcli 或任何命令行工具**）
- **火山引擎 · Coding Plan**
  - 同一账号可与 Agent Plan 同时订阅、各自独立开关；5 小时（session）/ 每周 / 每月三个窗口
  - 官方接口只给已用百分比与重置时间，照搬展示（进度条 + 已用/剩余百分比 + 重置时间），不反推次数
  - 数据来源：火山 OpenAPI `GetCodingPlanUsage`，账号 AK/SK 签名调用
- **火山引擎 · 语音服务**（ASR 语音识别 / TTS 语音合成）
  - 每个账号可配 1–10 个语音应用，各自独立额度（已用/共 小时或次数 + 到期）
  - **每个应用内 ASR / TTS 可分别独立开关**：例如 ASR 额度用尽（0%）可只关 ASR、保留 TTS
  - 数据来源：火山公开 OpenAPI `ResourcePacksStatus`，账号 AK/SK 签名调用
  - 每个语音应用需填 AppID（可选备注名，因官方接口拿不到应用名）

### 两种登录方式
- **AK/SK 登录**：传统方式，可查 Agent Plan / Coding Plan / 语音全部服务。
- **网页登录（免 AK/SK、无需实名认证）**：点按钮在系统浏览器打开火山官方页面登录授权，App 全程不接触账号密码，授权后自动跳回。可查 **Agent Plan / Coding Plan**（未实名账号也行）；语音服务仍需 AK/SK。网页凭证每 **48 小时**需重新授权一次（面板/设置会出现「重新授权」入口，点一下走同样的浏览器授权即可）。

> 架构已预留**多平台**（将来可加硅基流动、阿里云等）和**任意多账号**，加新的不影响旧配置。

## 把做好的 App 发给朋友用（直接用，不用构建，零依赖）

把 `outputs/My Quota Bar.app` 这**一个文件夹**发给朋友（AirDrop / 压缩包 / 网盘）。App 是 universal，**Apple Silicon 和 Intel Mac 都能跑**。**朋友无需安装任何命令行工具**：查套餐可直接用网页登录（连 AK/SK 都不用、无需实名），要用语音再填 AK/SK。

因为是个人自编、没有苹果开发者证书公证，朋友第一次打开会被 macOS 拦。放行方式（只需一次）：

**方式 A（推荐，一条命令）**：把 App 放到「应用程序」后，终端运行（路径改成实际位置）：
```bash
xattr -cr "/Applications/My Quota Bar.app"
```
然后正常双击打开。

**方式 B（纯鼠标）**：右键点 App →「打开」→ 弹窗再点「打开」；若没有「打开」按钮，去「系统设置 → 隐私与安全性」最下方点「仍要打开」。

> 这不是病毒，只是苹果对"未公证应用"的默认拦截。本应用纯本地运行、不上传任何数据。

## 自己从源码构建（开发者）

### 环境要求
- macOS 14 及以上
- Swift 6（装 Xcode 或 Command Line Tools）
- **不需要任何命令行工具依赖**（arkcli / node 都不需要了）

### 构建
```bash
git clone https://github.com/tangyangguang/my-quota-bar.git
cd my-quota-bar
./build-app.sh
open "outputs/My Quota Bar.app"
```
菜单栏出现图标 + 数字。产物在 `outputs/My Quota Bar.app`，可直接发人。

## 配置（两步）

### 第一步：添加账号（两种方式二选一）
1. 点菜单栏图标 →「设置」→「账号」Tab → 左下角「+」。
2. 选平台（火山引擎）→ 在「AK/SK」与「网页登录（免密钥）」之间选择：
   - **网页登录**：点「在浏览器中登录授权…」→ 在火山官网登录并同意 → 浏览器提示成功后回到 App，识别出账号后点「添加账号」。仅支持 Agent Plan / Coding Plan；每 48 小时按提示重新授权一次。
   - **AK/SK**：填 **Access Key ID / Secret Access Key**（火山控制台「访问控制 → API 访问密钥」创建）→ 可点「测试连接」自动填账户名称（可改）。可查全部服务含语音。AK/SK 加密存 macOS 钥匙串，一次配好长期保存。
3. 点「添加账号」。同一火山账号无论用哪种方式都不能重复添加。

### 第二步：配置服务（改了立即生效，不用点保存）
1. 左边栏按平台分组账号；点选账号后，右侧分「账号 / 套餐 / 语音」三个分组。
2. **套餐 · Agent Plan / Coding Plan**：打开对应卡片开关 → 点「测试」验证（两个套餐相互独立，可只开一个；网页登录账号默认已开启）。
3. **语音（仅 AK/SK 账号）**：点「语音」标题右侧「添加应用」→ 填 AppID（可选备注）→ 用「语音识别 ASR / 语音合成 TTS」两个复选框按需要开关 → 点「测试」。可加多个应用。网页登录账号不显示语音配置。
   - **没有语音总开关**：某个应用 ASR/TTS 都不勾 = 该应用不拉数、面板不显示（已填 AppID/备注保留）；例如 ASR 用尽就只取消 ASR、保留 TTS。
4. 所有改动**立即生效并刷新面板**，没有保存按钮。

**换密钥 / 重新授权**：AK/SK 账号在「账号」分组点「更换密钥…」，先「测试连接」通过才能保存；网页登录账号点「重新授权…」（或面板账号名旁的橙色「重新授权」）走一遍浏览器授权，须登录同一个火山账号。

**开机自动启动**：到「通用」Tab 打开「开机自动启动」。

## 使用

点菜单栏图标看全部账号服务；点「设置」打开设置窗口：
- **账号 Tab**：左边栏按平台分组账号（可拖动/上下移动排序；左下 `+`/`−` 增删），右侧单页管理账号信息与服务开关，**改了立即生效**。
- **通用 Tab**：菜单栏常驻显示哪个指标、刷新间隔、开机自动启动、版本号。

特性：设置即时生效、全 App 单一刷新调度器、最多 4 个账号并发、失败退避、分项失败保留旧值、删除/修改后丢弃旧响应、休眠/断网感知、纯本地不上传。

## 加新账号 / 新服务 / 新平台（开发者）

见 [PROJECT_RULES.md](./PROJECT_RULES.md) 的「加新平台 / 新服务」节。要点：每个服务「照搬原样」，写自己的 Provider（取数 + test）+ 展示卡片（`ServiceContent` 加 case）；数据模型用合成 Codable、账号 UUID 保持不变（钥匙串凭证按它存）。
