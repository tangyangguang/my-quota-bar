# My Quota Bar

一个 macOS 菜单栏应用，常驻菜单栏查看多个账号下各项服务的剩余额度。**本机应用，纯本地运行，不上传任何数据，零命令行依赖。**

> 项目背景与设计原则见 [PROJECT_RULES.md](./PROJECT_RULES.md)（唯一权威文档）。

## 信息层级

**平台 → 账号 → 服务 → 服务实例 → 额度**。面板先按平台、再按账号分组；账号内先 Agent Plan 后语音。语音 AppID 是语音服务内部实例。

## 当前支持

- **火山引擎 · Agent Plan**
  - 5 小时 / 每周 / 每月 三个窗口：进度条 + 剩余百分比 + 已用/总量 + 重置时间
  - 数据来源：火山 OpenAPI `GetAFPUsage`，用账号 AK/SK 签名调用（**无需 arkcli 或任何命令行工具**）
- **火山引擎 · 语音服务**（ASR 语音识别 / TTS 语音合成）
  - 每个账号可配 1–10 个语音应用，各自独立额度（已用/共 小时或次数 + 到期）
  - 数据来源：火山公开 OpenAPI `ResourcePacksStatus`，账号 AK/SK 签名调用
  - 每个语音应用需填 AppID（可选备注名，因官方接口拿不到应用名）

> 架构已预留**多平台**（将来可加硅基流动、阿里云等）和**任意多账号**，加新的不影响旧配置。

把 `outputs/My Quota Bar.app` 这**一个文件夹**发给朋友（AirDrop / 压缩包 / 网盘）。App 是 universal，**Apple Silicon 和 Intel Mac 都能跑**。**朋友无需安装任何命令行工具，只要有自己的火山 AK/SK 即可。**

```bash

```
然后正常双击打开。

**方式 B（纯鼠标）**：右键点 App →「打开」→ 弹窗再点「打开」；若没有「打开」按钮，去「系统设置 → 隐私与安全性」最下方点「仍要打开」。

> 这不是病毒，只是苹果对"未公证应用"的默认拦截。本应用纯本地运行、不上传任何数据。

## 自己从源码构建（开发者）

### 环境要求
- macOS 14 及以上
- Swift 6（装 Xcode 或 Command Line Tools）
- **不需要任何命令行工具依赖**（arkcli / node 都不需要了）

### 构建
```bash
git clone https://github.com/tangyangguang/my-quota-bar.git
cd my-quota-bar
./build-app.sh
open "outputs/My Quota Bar.app"
```
菜单栏出现图标 + 数字。产物在 `outputs/My Quota Bar.app`，可直接发人。

## 配置（两步）

### 第一步：添加账号
1. 点菜单栏图标 →「设置」→「账号」Tab → 左下角「+」。
2. 选平台（火山引擎）→ 填 **Access Key ID / Secret Access Key**（火山控制台「访问控制 → API 访问密钥」创建）。
3. 点「测试连接」（可选，但建议）→ 通过后自动填入账户名称（可改）。
4. 点「添加账号」。AK/SK 加密存 macOS 钥匙串，**一次配好永久保存，不用重复输入**。

### 第二步：配置服务
1. 左边栏按平台分组账号；点选账号后，右侧用分段按钮切换「账号信息 / 服务管理」。
2. **Agent Plan**：打开服务卡片开关 → 点「测试」验证。
3. **语音服务**：打开服务卡片开关 → 添加 AppID（可选备注）→ 点「测试」。可加多个实例；关闭服务不会删除 AppID。
4. 点当前页面底部保存按钮。切换账号或关闭窗口时，如有未保存修改，App 会提示保存、放弃或取消。

## 使用

点菜单栏图标看全部账号服务；点「设置」打开设置窗口：
- **账号 Tab**：左边栏按平台分组账号（可拖动/上下移动排序；左下 `+`/`−` 增删），右侧明确分成账号信息与服务管理。
- **显示 Tab**：菜单栏常驻显示哪个指标；各服务独立的刷新间隔。

特性：全 App 单一刷新调度器、最多 4 个账号并发、失败退避、分项失败保留旧值、删除/修改后丢弃旧响应、休眠/断网感知、纯本地不上传。

## 加新账号 / 新服务 / 新平台（开发者）

见 [PROJECT_RULES.md](./PROJECT_RULES.md) 的「加新平台 / 新服务」节。要点：每个服务「照搬原样」，写自己的 Provider（取数 + test）+ 展示卡片（`ServiceContent` 加 case）；改数据结构时保持**防御式 Codable**，旧配置永不丢。
